3. CANDIDATE SELECTION & ARCHITECTURAL RATIONALE
--------------------------------------------------------------------------------
Selected Candidate: SGDClassifier (HashingVectorizer, 512 features)

Rationale:
1. Edge Hardware Compatibility (ESP32): The EdgeSpam-IoT edge inference node
   runs on an ESP32 microcontroller with strict SRAM/Flash constraints. HashingVectorizer
   operates with ZERO dictionary storage overhead by hashing tokens directly into 512 bins.
2. Sparse L1 Regularization: SGDClassifier with penalty='l1' forces non-essential
   weights to exact zero, allowing lightweight C header export (model_weights.h).
3. Probability Output: Configured with loss='log_loss', enabling calibrated spam
   confidence scores via predict_proba() for both API and Edge interfaces.
4. Top Edge Performance: Achieved highest Spam Recall (72.48%) and Spam F1 (68.03%)
   among all edge-compatible hashing models on the unseen test set.
